# Data: sources, rights and reproducibility

## No market data is distributed

This project ships **no market data**. What it contains:

| Item | Nature | Redistribution |
|---|---|---|
| `examples/sample_data/DEMOA.csv`, `DEMOB.csv` | Simulated (seeded random walk) | Free: generated by this project |
| Synthetic demo mode (SYN1 to SYN5) | Simulated at run time | Free |
| Screenshots in `docs/screenshots/` | Taken in synthetic mode; the Research page shows summary statistics of the study | Derived / simulated |
| `reports/`, `experiments/results/`, tables in `README.md` and `RESEARCH.md` | Summary statistics (returns, ratios, drawdowns) computed from the reference dataset; no price series | Derived statistics. Not the dataset; judged low risk, but not a licensed redistribution of anything |
| `experiments/MANIFEST.json` | Checksums and metadata of the reference dataset | Contains no prices |

## The private reference dataset

The published study was computed from Yahoo-derived adjusted daily prices for
SPY, QQQ and IWM (1993-01-29 to 2026-10-30, 8,497 sessions, retrieved
2026-11-16). **Redistribution rights for that dataset have not been
established**: Yahoo's terms allow personal use and do not grant a licence to
republish. "Publicly downloadable" is not the same as "redistributable". The
author therefore keeps it in a private repository and it is not part of any
public copy of this project.

`experiments/MANIFEST.json` records its provider, retrieval time, coverage,
adjustment convention, file schema, a SHA-256 per file and the close-price
fingerprint `76f294e718c47ee2`, plus the list of outputs that depend on it.

| Situation | `python experiments/trend_vs_buyhold.py --verify` |
|---|---|
| Reference dataset present (private repository) | PASS, 429 numeric results, largest difference 0 |
| Dataset absent (public copy) | Downloads the same tickers and dates for your own use and compares. Provider revisions shift results slightly (1.3e-6 relative was seen within hours; expect more after each dividend). The exact published figures cannot be reproduced without the private dataset |

## The four data sources in the app

| Source | Label | Notes |
|---|---|---|
| Yahoo Finance daily data | green **YAHOO DAILY DATA** | Latest available completed daily data, refreshed by completed session (see below). Not a live quote feed; not point-in-time; rate limited. On failure the last verified data is shown with a warning; synthetic data is never substituted silently |
| Frozen research snapshot | violet **FROZEN RESEARCH SNAPSHOT** | Only offered where the private dataset folder exists |
| My own CSV files | blue **USER-SUPPLIED DATA** | Uploaded files stay in the browser session and are not stored |
| Synthetic demo data | amber **SYNTHETIC DEMO DATA** + warning on every page | Simulated instruments with invented names |

The active source is written into every export (`config.json` -> `data`), and
the HTML report prints a banner for synthetic data.

## Bringing your own data

One CSV per instrument, named after its ticker (`SPY.csv`).

| Column | Required | Notes |
|---|---|---|
| `date` (or `datetime`, `timestamp`, or the first column) | yes | any format pandas parses |
| `open`, `high`, `low`, `close` | yes | positive numbers; `high >= low` |
| `volume` | no | |
| `adj close` | no | if present, all four prices are scaled by adj close / close |

```python
from quantlab.data import CsvProvider
data = CsvProvider("path/to/folder").fetch(["SPY", "TLT"])
```

In the dashboard choose **My own CSV files** and upload. A file that cannot be
used is reported by name with the reason; valid files still load; nothing is
repaired or filled in. Only use data you have the right to use.

To download compatible data from Yahoo for personal use:

```python
from quantlab.data import CachedProvider, YFinanceProvider
data = CachedProvider(YFinanceProvider()).fetch(["SPY", "QQQ", "IWM"], "1993-01-01", "2026-10-31")
```

## Is live data up to date?

For the Yahoo source the app shows the latest available completed daily data
and says how current it is: current, waiting for the provider to publish, or
out of date, per instrument. It checks the provider when a newly completed NYSE
session is missing, and a **Refresh market data** button forces a check. Every
check reports what actually happened: Updated, Checked; unchanged, Refresh
limited, Refresh failed (the last verified data stays in use), or No usable
data. A bar for a session that has not officially closed is never used, and a
missing session is never filled in. Frozen, uploaded and synthetic data are not
refreshed and make no freshness claim. Details: [methodology.md](methodology.md).

This is daily history, not a live quote feed, and refreshing happens when
someone uses the app: nothing runs on a schedule.

## Provider limitations

- Adjusted prices are revised whenever a dividend is paid: not point-in-time.
- Adjusted levels are not the prices that traded; returns are what matter.
- Unofficial API: rate limits and outages surface as a clear error.
- A bar dated today is dropped because the session may be incomplete.
- Funds that closed are absent: survivorship bias.
